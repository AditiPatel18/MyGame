# 📖 Overview

2D Treasure Hunting Game is a desktop adventure game developed in Java where players explore a tile-based world, collect keys and items, unlock doors, avoid obstacles, and search for hidden treasures.

The project demonstrates Object-Oriented Programming principles, game loop implementation, collision detection, sprite animation, tile map rendering, and sound integration.

# 🚀 Getting Started

Clone Repository

```bash
git clone https://github.com/AditiPatel18/MyGame.git
```

Open Project

```bash
cd MyGame
```

Run

```bash
mvn clean install

mvn exec:java
```

or run **Main.java** directly from your IDE.
